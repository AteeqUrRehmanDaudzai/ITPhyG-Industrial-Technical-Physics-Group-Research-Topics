index.html   Standalone responsive website.

How to use
----------
1. Open index.html in Chrome/Edge/Firefox.
2. Edit the text directly in the HTML if needed.
3. For Google Sites, use this file as the layout/content blueprint.
   Google Sites does not directly import a full HTML theme, but you can reproduce
   the same page structure with top navigation, section cards, buttons and embeds.
4. If you host this HTML elsewhere, you can embed it in Google Sites using:
   Insert > Embed > By URL.

Suggested Google Sites top navigation:
- Home
- Grid Intelligence
- RECs & Society
- Advanced PV
- Smart Buildings & IoT
- Thermal Management
- Research Topics

The lock/shield cybersecurity graphics are inline SVG, so there are no external image dependencies.
